## 产品与工程约束

- Windows x64 优先；Electron + 随包 Node 的本地 Next.js/React 应用，本地 SQLite，单用户单项目写入。
- OpenMAIC 复用真实课堂、教师、AI 同学、白板、课件、测验、互动与相关存储合同；应用新增来源/领域准入和桌面适配。
- 暖纸色、朱砂主按钮、紧凑导航与文档工作区；提供纸色、浅色、暗色及跟随系统设置。
- 外观与教学表达分别定制。教学表达设置按任务冻结，不能绕过来源审核。
- AI 只提交候选，已核实知识点表是教学权威源；课件、动态发言、白板和互动同样受约束。档案导出为 Markdown/JSON，课堂使用结构化课件和本地资产。
- 先完成教师、基础互动与默认零至两名 AI 同学；最终交付六类互动、PBL、完整编辑、Pro 工作台/技能链、媒体与导入导出。本人作答与 AI 演示分别记录。
- 领域任务与课堂由本地服务运行，Electron 管理服务；重启依据四层检查点恢复，等待审核/作答时保持等待。

## 第一阶段的完成标志

先读《开工任务清单》M0：安装包在没有开发 Node 的 Windows 环境启动真实 ClassroomSurface，幻灯片、测验和互动能操作，提交重启可读。通过后进入来源/知识/计划领域建设，再实现正式课程、教师、同学与学习闭环。

M0 使用审核过的固定内容，可以不依赖模型；已有领域骨架继续复用。M1—M4 通过表示备考闭环成立，最终产品仍需按 A—F 和 85 项能力逐项验收。A 没有单独 OMA ID，是跨批次真实课堂/资源前置；可选后端、模型基础及存储接口按实际依赖提前实施，不必等到其交付归属批次。

状态只在实现及相应验收成立后更新：待办收窄真实剩余工作，能力清单维护 status/evidence，上游适配记录维护实际采用范围。规划和任务清单不承载重复完成历史，不恢复已删除的进展报告，不承诺未经试验支持的全功能工期。
