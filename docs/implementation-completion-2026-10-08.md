## 本轮已验证的软件子项

- 本地 ComfyUI、Whisper 兼容 HTTP 与 FunASR 官方 WebSocket 已接入配置界面和媒体生成入口。配置仅进程内保存，状态隐藏凭据，并复用现有预算、频次、取消和来源准入。38项专项测试通过；未安装实际引擎/模型，不能声称真实推理已验收。
- 场景画布支持拖动、多选移动、尺寸调整、旋转、图层与已有计划保存；37项场景计划/画布测试通过。原有审核、来源与版本检查继续适用。
- 原生 PPTX 公式采用 PowerPoint `a14:m` 和 OMML，而非公式位图或仅 LaTeX 字符。8项实际导出文件 XML 测试通过；只支持明确覆盖的数学结构，不支持的公式仍报告资源缺口。
- MP4 持久任务、路由和界面已接通，实际帧字节作为检查点落库；取消后迟到结果不发布，重启不自动重跑，明确继续时复验检查点和来源。编码后先保存摘要绑定的全量解码回执，再发布文件；文件发布与状态之间发生中断时可复验原字节并完成结果核对。
- MP4 原生集成13项通过，包含从审核课程到持久任务、编码、全量解码、发布和校验下载的实际消费者；真实输出为 `output/mp4-runtime-tests/reviewed-lesson-publication.mp4`。每次集成都会生成新的课程身份并覆盖测试样本，最新 byteLength/SHA 及冻结媒体检查以同名JSON和交接核验回执为准。该结果是静音幻灯片/测验公开投影，不能当完整互动/语音课程播放。
- 文档原件存储 schema37 把提取文本与 PDF/Office 原二进制分别保存，在同一材料导入事务中绑定各自摘要与位置回执。原件下载按项目、generation、不可变版本和SHA核验；字节区间仅指提取文本。4项原件测试，以及来源/历史迁移/运行时合计58项测试通过。

生成总入口、PDF/Office提取与许可字体的当前软件子项已经落地；模型原生协议、初步Pro和课堂键盘/沉浸也已接入。数据库源码已迁移到schema39。用户现要求收束此批并交接，完整后续指令见 [交接提示词](agent-handoff-prompt-2026-10-08.md)，最新验证见 [交接检查点](handoff-checkpoint-2026-10-08.md)。这些子项不代表全部85项完成；旧145文件/1433测试和旧源码指纹仅为历史结果。
