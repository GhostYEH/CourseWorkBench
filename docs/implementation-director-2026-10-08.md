# 本地逐场景审核调度

日期：2026-10-08。本次未执行 build/package，改动未提交。

本地正式课堂已接入 Director 的受审核调度子集。保存时冻结课程版本、文档/证据包摘要、run、本人身份、场景顺序与角色摘要。逐场景队列包含教师及最多两名已启用的模拟同学；测验、互动和 PBL 交还本人。

教师调用复用 `generateGuarded` 的凭据、来源、教师权限、共享额度、期限和取消控制。生成结果先落入草案讲解卡；人工核对具体候选摘要及来源后才能批准。再次明确继续时，服务从已审核卡片读取正文，复用课堂播放、同学记录或场景推进。课堂副作用、调度状态和请求回执在同一 SQLite 事务中提交。

模拟同学只复述被冻结的公开陈述，不调用 provider，也不冒充生成式多代理。记录属于 simulation，不进入本人答题、正式交付或掌握结论。本人等待期间不发模型请求，也不静默跳场景。

Director 状态保存在服务专属 `classroomKV` 分区，通用 HTTP KV 禁止访问 `director:` 前缀。读取/重启不会派发；在途未知结果不会重试，需显式停止并新建调度才能选择新调用。原命令响应丢失时，面板沿用原请求标识读回。暂停和停止只取消此调度的在途控制器；迟到结果不会覆盖停止或人工暂停状态，旧 HTTP 响应不能覆盖更新的控制状态。

入口为已有本地课堂面板与 `/api/study/director`，公共在线房间不挂此面板。集成后刷新父课堂状态并同步当前场景。14 项定向回归覆盖真实两个场景的生成/审核/交付/完成、本人等待、模拟隔离、取消、未知恢复、事务回滚和 HTTP 范围；另有 2 项异步响应顺序回归。最终 145 文件 / 1433 项源码测试及类型/lint/格式/工程边界均通过，详见[当前实施记录](implementation-media-pptx-2026-10-08.md)。
