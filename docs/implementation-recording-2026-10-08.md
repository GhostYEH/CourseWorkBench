# 麦克风录制实现与验收边界

日期：2026-10-08。按用户要求未执行 build/package。

`/workbench/media` 的录音转写类型已有录制入口。用户点击开始才申请音频设备；可停止、试听、丢弃或保存并选择录音。录音保存到当前项目的 SQLite 课堂资产，可随现有项目备份恢复；它只代表本人录音，不是经过审核的教学事实。保存后远端转写授权保持未勾选，发起转写仍走既有课程准入、共享额度和候选审核。

录制写入单声道 PCM16 WAV，实际设备采样率写入头部，真实时长由帧数计算；最短 0.1 秒、最长 5 分钟，至多 16 MiB。达到时长或字节限额自动停止，不播放麦克风回声。取消申请、初始化期间设备断开、迟到权限、页面卸载和项目变化均释放节点/流/音频上下文，迟到初始化不得重新进入录音。

`POST /api/study/media/recordings` 在读取请求前后核验项目代际，按真实流字节限额读取，并严格校验 WAV 格式、长度和实际时长。录音请求号绑定实际内容，响应丢失后沿用原请求号重试读回同一资产；同一请求号换内容拒绝覆盖。保存不调用模型、不代表转写授权；客户端核验保存回执的 SHA-256、长度和时长。

转写以实际录音帧数校验申请秒数，不能通过虚报时长缩小预算；进入任务后原录音禁止普通覆盖/删除/回收，直到现有任务引用仍存在。watchdog 与结算前重验输入分区、类型和摘要。

新增 7 项设备生命周期/PCM 回归、4 项 HTTP/客户端保存回归，以及媒体服务中的真实时长/引用保护回归。独立 reviewer 核实并复核了初始化期间断开设备的竞态修复及 ASR 输入引用保护；其只读审查不替代运行验证。

真实麦克风、OS 拒绝/撤回权限、Electron 安装态音频捕获与长时间录制仍待最终产物验收。当前使用 Web Audio 的 ScriptProcessor；它是已有浏览器接口，尚未升级为 AudioWorklet。FunASR/Whisper 本地模型、声音设计/克隆、完整课堂音画同步仍未接入。完整源码检查结果见[媒体与课件实施记录](implementation-media-pptx-2026-10-08.md)与 `output/source-verification-2026-10-08.json`。
