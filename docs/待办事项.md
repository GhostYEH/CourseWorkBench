## 必须持续覆盖的合同场景

2026-10-04 已关闭 N1：`apiFetch` 必须携带共享响应 schema，先校验信封及 HTTP 状态，再校验实际 DTO；所有界面调用已迁移，课堂 RuntimeStore 的独立错误格式仅在失败的运行接口处理。修复课程接口透传数据库记录与缺失课程返回成功信封的问题。`pnpm check` 全部通过（47 个测试文件 / 311 个用例，无跳过），新增 23 个用例覆盖异常响应、取消、错误格式，以及临时 SQLite + 实际路由 Response 经客户端校验的材料/考纲/审核/计划/run/课程与设置闭环；既有课堂测试追加了测验收据、资源清单与播放位置的实际 payload 校验。只读复核未发现可验证缺陷。这些自动回归不替代真实学科材料或独立环境签核。

- 无来源候选不能进入权威知识或正式教学；引用存在但不支持时拒绝发布。
- 未授权或旧项目请求拒绝；来源版本替换后关联场景暂停/失效并可重新审核。
- 新编题自称真题不能获得真题身份；AI 同学答案只写入 simulation。
- iframe 伪造高分不能直接判分；提交后响应前崩溃恢复既有提交且不重复计数。
- 未审核或已撤回的课程版本不能进入课堂；模型草案只作为草案，来源失效在 provider 请求发出前阻断，失败尝试也计入 run 台账。
- 已提交白板动作断连后不能重复执行；不支持恢复的互动明确重置且不丢已保存本人答案。
- 端口/会话变化不复用旧授权；模型断网或预算耗尽明确失败/等待，不模拟进度。
